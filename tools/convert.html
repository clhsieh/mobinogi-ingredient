配方 CSV → data.js 轉換工具

以後要更新配方，只要編輯 recipes.csv（可用 Excel / Numbers / Google 試算表打開），再用這個工具轉換成 data.js，取代專案裡的檔案即可。 這個頁面完全在瀏覽器內運算，不會上傳任何資料。

1. CSV 內容（可直接貼上／編輯）

欄位說明（不需要另外想英文 id，直接用物品名稱就好）：
name 物品名稱，同時當作唯一代碼，其他配方用這個名稱引用
category 大分類（自由命名，會顯示在左側第一層篩選 tab）
subcategory 小分類（自由命名，選填；同一大分類下若有填， 會多顯示第二層篩選 tab，留空就沒有第二層）
craft_time_sec 每次製作時間，可以直接寫秒數（例如 100）， 也可以寫 1小時40分、90秒、2分30秒 這種格式， 會自動換算成秒數
output_qty 每次產出數量 —— 這兩欄「原始材料」留空即可
materials 所需材料，格式 材料名稱:數量，多個材料用 ; 分隔，例如 鐵礦石:3;木材:1
（物品名稱本身請避免包含 :、;、, 這幾個符號，以免跟格式衝突）

不需要列出原始材料：只要某個材料名稱從來沒有出現在 name 欄，網站會自動把它當成「直接採集」的原始材料，不用特地加一列。
同一物品可以有多種配方：用同一個 name 寫好幾列，每一列填不同的 materials（分類/時間/產出可以只填第一列， 其餘留空），網站會讓使用者自己選要用哪一種配方來計算。

2. 產生的 data.js

產生後請把下載的 data.js 覆蓋到專案根目錄，重新整理 index.html 即可看到更新後的配方。
如果本機有裝 Node.js，也可以不用這個頁面，直接在專案根目錄執行 node tools/build.js，會自動讀 recipes.csv 並覆蓋 data.js，不用手動下載/搬移檔案。
